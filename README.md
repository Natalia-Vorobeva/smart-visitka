# Калькулятор сайта-визитки

Интерактивный инструмент для расчёта стоимости разработки сайта-визитки. Пользователь выбирает опции, видит предпросмотр в реальном времени и отправляет заявку в Telegram.

🔗 **Демо:** [https://natalia-vorobeva.github.io/smart-visitka/](https://natalia-vorobeva.github.io/smart-visitka/)

---

## 🚀 Возможности

- **Два режима работы:**
  - *Стандартный дизайн* – адаптивный шаблон с возможностью замены блоков (услуги/преимущества, портфолио/прайс).
  - *Вёрстка вашего макета* – расчёт стоимости по сложности, описание услуг.
- **Выбор сроков выполнения** (стандарт, ускоренный, экспресс) с автоматической наценкой.
- **Кастомизация внешнего вида** (цвет кнопки, цвет фона сайта, текст кнопки, три варианта логотипа).
- **Динамический предпросмотр** – визуализация сайта в реальном времени.
- **Блок гарантий** (круглые плашки с иконками, поочерёдная анимация при загрузке).
- **Отправка заявки в Telegram** с защитой от спама (математическая капча + honeypot + минимальное время заполнения).
- **Скидка 5% для повторных клиентов** (сохраняется email в `localStorage`).
- **Адаптивная вёрстка** (мобильные устройства, планшеты, десктоп).
